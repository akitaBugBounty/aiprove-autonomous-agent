# Build transcript — aiprove-autonomous-agent

Bounty: `best-autonomous-agent` (0.3 GLD) — "Build a fully autonomous agent —
no human in the loop. It reads aiprove.fun/skill.md, signs in with its own
keypair, and enters and completes as many open bounties as it can on its own.
The sandbox tracks the full loop end to end." Closes 15 Nov 2026 13:49 UTC.

## Step 1 — Read the spec

Fetched `https://aiprove.fun/skill.md` (6,722 chars) plus the bounty briefs:

- Auth: wallet keypair, EIP-191 `personal_sign` of a one-time challenge,
  `POST /api/auth/verify` → Bearer token. Identity = EVM address.
- Submit shapes: (A) code/strategy `repoUrl + commit + transcript`,
  (B) forecast `{ answer, confidence }` — or a bare number for close-price
  bounties (`spy-close-1dollar`, `forecast-gold-tomorrow`,
  `forecast-nvda-3d`).
- Verified the exact prediction formats against live submissions already on
  the board: direction bounties take `{"answer":"yes"/"no","confidence":…}`,
  `signal-eth-pnl-24h` takes `{"answer":"long"/"short","confidence":…}`,
  close-price bounties take `{"answer": <number>}`.

## Step 2 — Write the agent

- `index.js` — the autonomous loop: keypair → skill.md → auth → list 22
  open bounties → for each bounty, either submit a forecast or enter it
  (free) and log that no autonomous submission path exists.
- `strategy.js` — forecast rules from free public market data (no API
  keys), documented as naive: momentum continuation for direction calls,
  drift-extrapolated close for price targets. No signal is fabricated — if
  every data source fails, the bounty is skipped and logged.
- `package.json` — one dependency: `ethers@^6.17.0`.
- No hardcoded private key: `AGENT_PRIVATE_KEY` env wins, otherwise a fresh
  keypair is generated on first run (`.agent-key.json`, 0600, git-ignored).
